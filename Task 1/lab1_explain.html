Как читаются данные read_datasets

Файл может содержать несколько наборов точек. Разделитель — пустая строка или строка, начинающаяся с #.

# Набор 1
0.5 1.0
1.0 2.3
...

# Набор 2
0.0 0.0
1.0 1.2
...
читаем строку за строкой→ пусто / # → закрыть набор→ иначе → (x, y) в текущий набор→ список наборов

Проверка неравномерного шага

Точки внутри набора не обязаны идти с одинаковым интервалом по x. Перед отрисовкой набор сортируется по x, а расстояния между соседними точками (np.diff) выводятся, чтобы наглядно показать, что шаг действительно неравномерный.

1
Отсортировать точки набора по x
2
Посчитать разности соседних x — это и есть "шаги"
3
Если шаги разные — данные неравномерные, и это нормально: график строится по фактическим координатам, без допущения о регулярной сетке

Визуализация данных

Точки — реальные координаты из файла (после сортировки по x). Линии не проводятся: график именно точечный, как того требует scatter().
