Лабораторная работа 5 — моделирование непрерывных случайных величин

Ипатенков Г.А. · ИВТ-4 · вариант 6 — равномерный (1; 7), гауссовский N(6; 2²), усечённый рэлеевский b = 1.5 на (0; 4.5), N = 6000

Основы Обратная функция ЦПТ Метод Неймана Гистограмма Визуализация

Основы

Непрерывная случайная величина X задаётся функцией распределения и плотностью вероятности:

F(x) = P(X < x),    w(x) = dF(x)/dx,    ∫ w(x) dx = 1

На компьютере есть только базовые случайные числа rᵢ, равномерно распределённые на (0, 1): это random(). Любой другой закон получается преобразованием этих чисел. В лабораторной используются три способа:

Метод обратной функции: когда F(x) можно явно обратить (равномерный закон).
Центральная предельная теорема: сумма многих равномерных величин почти нормальна (гауссовский закон).
Метод Неймана: универсальный отбор точек под кривой плотности (усечённый рэлеевский закон).

1. Равномерный закон — метод обратной функции

F(x) возрастает, поэтому у неё есть обратная функция x = G(y). Если подставить в G равномерное r, получится x с нужным законом:

xᵢ = G(rᵢ) = F⁻¹(rᵢ)

Для равномерного закона на (a, b), формула (65):

F(x) = (x − a)/(b − a)  ⇒  xᵢ = rᵢ·(b − a) + a   (68)
mₓ = (a + b)/2  (66),    σₓ² = (b − a)²/12  (67)

Вариант 6: (a, b) = (1; 7), значит mₓ = 4, σₓ² = 3.

2. Гауссовский закон — центральная предельная теорема

Функцию Лапласа (73) нельзя обратить в элементарных функциях. Зато сумма n независимых равномерных величин по ЦПТ стремится к нормальному закону:

Шаг 1. v = r₁ + r₂ + … + rₙ, при этом m_v = n/2, D_v² = n/12
Шаг 2. Нормируем: ξ = (v − m_v)/D_v = √(12/n) · Σ(rᵢ − 0.5) ~ N(0, 1)
Шаг 3. Переходим к нужным параметрам: X = D·ξ + m
w(x) = 1/√(2πD²) · exp(−(x − m)²/2D²)   (74)

На одно гауссовское число тратится n базовых, коэффициент использования датчика равен 1/n. Значения ограничены промежутком m ± D√(3n), поэтому «хвосты» обрезаны. В методичке в шаге 2 в знаменателе напечатано D_v², правильно — D_v.

3. Усечённый рэлеевский закон — метод Неймана

w(x) = x/b² · exp(−x²/2b²),    F(x) = 1 − exp(−x²/2b²)   (69)

Плотность вписывается в прямоугольник (0, x_max) × (0, M), где M = max w(x) = w(b) = e^(−1/2)/b.

Шаг 1. Бросаем случайную точку: R₁ = x_max·rᵢ, R₂ = M·rⱼ
Шаг 2. Если R₂ ≤ w(R₁), точка под кривой, и xᵢ = R₁ идёт в выборку
Шаг 3. Иначе точка отбрасывается, повторяем

После усечения плотность нормируется на вероятность попасть в интервал:

w_ус(x) = w(x)/F(x_max),    F_ус(x) = F(x)/F(x_max),    0 < x < x_max

Доля принятых точек равна площади под кривой, делённой на площадь прямоугольника: F(x_max)/(M·x_max). Неусечённые моменты (70), (71): mₓ = b√(π/2), σₓ² = (2 − π/2)b².

Гистограмма, полигон и выборочные моменты

Интервалы. k = 5·lg N, при этом 9 < k < 21. Для симметричных законов k нечётное.
Ширина. d = 1.02·(x_max − x_min), Δx = d/k. Для одностороннего закона левая граница a = 0.
Гистограмма. ωᵢ = kᵢ/(N·Δx), сравнивается с w(x) в центрах интервалов.
Полигон. F_q = (k₁ + … + k_q)/N, сравнивается с F(x) в концах интервалов.
mₓ = (1/N)·Σxᵢ  (75),    D² = (1/N)·Σ(xᵢ − m)²  (76),    D² = (1/N)·Σ(xᵢ − mₓ)²  (77)
