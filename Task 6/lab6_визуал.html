Аналитика Трапеции Монте-Карло Выбор N Итоги

Аналитическое решение

Первообразная табличная: ∫ dx/(1 + x²) = arctg x + C. По формуле Ньютона–Лейбница:

I = arctg 2 − arctg 0.5 = arctg((2 − 0.5)/(1 + 2·0.5)) = arctg(3/4) ≈ 0.6435011

На [0.5; 2] функция положительна и убывает от f(0.5) = 0.8 до f(2) = 0.2. Интеграл — это площадь под кривой.

Метод трапеций

Отрезок делится на N частей с шагом h = (b − a)/N. На каждой части кривая заменяется отрезком прямой, и площади трапеций складываются:

I ≈ h · [ (f(a) + f(b))/2 + f(x₁) + … + f(x_{N−1}) ]   (6)

Метод Монте-Карло

Способ 1 — выборочное среднее. uᵢ = a + (b − a)·rᵢ,   I* = (b − a)/N · Σ f(uᵢ)  (10). Каждая случайная точка даёт «столбик» ширины (b − a)/N.
Способ 2 — геометрический. Кривая вписывается в прямоугольник [a, b] × [0, M], M = f(0.5) = 0.8. Бросаем точки X = a + (b − a)r₁, Y = M·r₂ и считаем k — сколько точек под кривой: I* = M·(b − a)·k/N  (11).

Сколько испытаний нужно для ошибки 1%

По ЦПТ ошибка оценки распределена нормально. С надёжностью γ она меньше δ = t·σ/√N  (13), (14). Требуем δ = 0.01·I:

N = ( t·σ / (ε·I) )²,    γ = 0.997 → t ≈ 2.97 (правило трёх сигм)
Шаг 1. N₀ = 1000 пробных испытаний дают оценку σ*.
Шаг 2. По формуле находим N. Если N > N₀, добираем испытания.
Шаг 3. Считаем 100 независимых оценок I*ᵢ и их выборочное СКО.

Ошибка Монте-Карло убывает как 1/√N: чтобы получить ещё один верный знак, нужно в 100 раз больше точек. В способе 2 каждая точка несёт только «да/нет», поэтому σ одного испытания больше и точек нужно примерно в 5 раз больше.
