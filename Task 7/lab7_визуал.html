Этап 1 — отделение корня

f(x) = 0.5x + sin x − 1,    f′(x) = 0.5 + cos x,    f″(x) = −sin x

f′ = 0 при x = 2π/3 и 4π/3. В этих точках f ≈ 0.91 и f ≈ 0.23, обе значения положительные. Поэтому ось x пересекается только один раз, левее 2π/3.

Графически: уравнение переписывается как 0.5x − 1 = −sin x, корень — точка пересечения прямой и синусоиды. По знакам f(0.5) = −0.27 и f(1) = +0.34 получаем интервал локализации [A, B] = [0.5; 1].

Условия сходимости на [0.5; 1]

Дихотомия. f(A)·f(B) = −0.27·0.34 < 0 ✓. Больше ничего не требуется.
Хорды. f′ ∈ [1.04; 1.38] > 0, f″ ∈ [−0.84; −0.48] < 0, знаки постоянны ✓. Это случай «в» на рис. 9: неподвижен конец A (там f·f″ > 0), движение начинается от x₀ = B.
Простая итерация. φ(x) = x + g·f(x) (6), g = −2/(m + M) = −0.827. Тогда max|φ′| = 0.14 < 1 ✓. Запись «в лоб» x = 2(1 − sin x) даёт |φ′| = 2|cos x| > 1, и итерации расходятся.
Ньютон. f′ и f″ разных знаков, поэтому x₀ = A = 0.5. Проверка: f(x₀)·f″(x₀) = 0.13 > 0 ✓.

ε = 10⁻⁶ взята с большим запасом над машинной погрешностью 2.2·10⁻¹⁶ (пункт 3 задания).

Методы по шагам

Тест на квадратном уравнении (пункт 10)

x² − x − 6 = 0,   D = 1 + 24 = 25,   x₁,₂ = (1 ± 5)/2 → x₁ = 3, x₂ = −2

Для простой итерации записи: x = √(x + 6) у корня 3 и x = −√(x + 6) у корня −2, |φ′| ≈ 0.17 и 0.25. Все методы нашли оба корня с ошибкой меньше ε, значит процедуры написаны верно.

Итоги для уравнения варианта

Дихотомия надёжна, но медленна: отрезок за шаг уменьшается только вдвое. Хорды и простая итерация сходятся линейно. Ньютон сходится квадратично: число верных знаков примерно удваивается на каждом шаге. Логарифмы в Python: math.log — это ln, math.log10 — lg, math.log(x, a) — логарифм по основанию a.
