Ипатенков Г.А. · ИВТ-4 · вариант 6 — y′ = 0.4y + 0.9x² + 1.7, y(0) = 1, x ∈ [0; 2], h = 0.2

Аналитика Методы Сравнение Шаг РК-4 Таблица

Аналитическое решение

Параметры варианта: a = 0.4, b = 0.9, l = 1.7, n = 2. Уравнение y′ = (−1)ⁿ·a·y + b·x² + l линейное, с постоянными коэффициентами и неоднородностью-многочленом, поэтому решается в квадратурах: y = ȳ + y*.

Однородное уравнение. Из y′ − 0.4y = 0 и y = Ce^{λx} получаем λ = 0.4, значит ȳ = Ce^{0.4x}.
Частное решение. y* = Kx² + Lx + M. Подстановка даёт 2Kx + L − 0.4(Kx² + Lx + M) = 0.9x² + 1.7, откуда −0.4K = 0.9 → K = −2.25; 2K − 0.4L = 0 → L = −11.25; L − 0.4M = 1.7 → M = −32.375.
Начальное условие. y(0) = C + M = 1, значит C = 33.375.
y(x) = 33.375·e^{0.4x} − 2.25x² − 11.25x − 32.375

Численные методы

Эйлер (5): y_{i+1} = y_i + h·f(x_i, y_i). Шаг идёт по касательной в начальной точке. Порядок O(h).
Хойн (7): прогноз по Эйлеру, затем среднее двух наклонов, y_{i+1} = y_i + h/2·(K₁ + K₂). Порядок O(h²).
Рунге–Кутта IV (8): четыре наклона — в начале шага, дважды в середине, в конце; y_{i+1} = y_i + h/6·(K₁ + 2K₂ + 2K₃ + K₄). Порядок O(h⁴).
