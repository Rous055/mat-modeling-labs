Интервал унимодальности

Прямые методы находят экстремум только у унимодальной функции, то есть у функции с одним экстремумом на отрезке. Функция x²·cos(2x + 1) колеблется с растущей амплитудой: на [−4; 4] у неё четыре локальных максимума, а глобального максимума нет.

f(x)выбранный интервал [1.5; 4]локальные максимумы

На [1.5; 4] максимум один. Эталон получен из f′(x) = 0, то есть из уравнения x·tg(2x + 1) = 1, методом Ньютона (лаба 7): x* = 2.812406, f(x*) = 7.452538.

Процедура исключения отрезка и три метода

Внутри [a, b] ставятся две точки x_L < x_R. Для максимума: если y_L > y_R, отбрасывается [x_R, b]; иначе отбрасывается [a, x_L]. Поиск идёт, пока b − a > 2ε. Ответ — середина оставшегося отрезка.

Дихотомия. x_L,R = (a + b)/2 ∓ δ/2 (6). Отрезок уменьшается почти вдвое за шаг, но каждый шаг — это два новых вычисления f.
Золотое сечение. x_L = b − τ(b − a), x_R = a + τ(b − a), τ = 0.618 (9). Одна точка переходит на следующий шаг, поэтому за шаг нужно одно вычисление, а отрезок уменьшается в Φ = 1.618 раза.
Фибоначчи. Точки ставятся в отношениях F_{n−i−1}/F_{n−i+1} и F_{n−i}/F_{n−i+1} (11). Число вычислений n задаётся заранее, итоговый отрезок равен (b − a)/F_n. Получаемая точность ε_n = (b − a)/(2F_n) + δ/2.

Методы по шагам

f(x)текущий [a, b]отброшенная частьx_L, x_R

Масштаб по x следует за интервалом, поэтому на поздних шагах видно, как он сужается. У Фибоначчи ползунком можно менять n: чем больше n, тем меньше итоговый отрезок.
