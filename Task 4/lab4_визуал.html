Лабораторная работа 4 — метод наименьших квадратов

Ипатенков Г.А. · ИВТ-4 · вариант 6 — тестовые точки параболы y = x² + 2x + 1

Идея метода Схема Горнера Визуализация

Идея МНК

По точкам (xₖ, yₖ) нужно подобрать полином P(x) = C₀ + C₁x + C₂x² + … так, чтобы сумма квадратов отклонений была минимальна:

S = Σ (P(xₖ) − yₖ)² → min

Приравнивая к нулю производные S по каждому коэффициенту Cᵢ, получаем систему линейных уравнений (нормальные уравнения):

Матрица A: элемент Aᵢⱼ = Σ xₖ^(i+j)
Вектор B: элемент Bᵢ = Σ yₖ·xₖ^i
Решаем A·C = B → получаем коэффициенты C₀, C₁, …, Cₙ

Степень полинома должна быть меньше числа точек, и на практике редко берут больше 5–7 — иначе система становится плохо обусловленной.

Схема Горнера

Вместо прямого вычисления C₀ + C₁x + C₂x² + C₃x³ (с явным возведением в степень) полином переписывается как:

P(x) = (...(( Cₙ·x + Cₙ₋₁)·x + …)·x + C₀)

Это то же самое значение, но считается за n умножений и n сложений вместо отдельного возведения в степень для каждого члена — быстрее и меньше накопленная ошибка округления.
